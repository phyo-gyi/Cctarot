# 🌟 CelestialCards_bot

`CelestialCards_bot` သည် 24/7 မပြတ်တောက်စေရန် GitHub Actions ကို အသုံးပြု၍ လည်ပတ်ထားသော Python Bot ဖြစ်ပါသည်။

---

## 🛠️ Feature များ

- **24/7 Auto Execution:** GitHub Actions Workflow ဖြင့် ၅ မိနစ်တစ်ခါ Auto Check/Restart လုပ်ဆောင်ပေးခြင်း။
- **Concurrency Control:** Bot အပြိုင် မပွင့်စေရန်နှင့် Trigger အသစ်လာပါက လုပ်ဆောင်လက်စ Workflow ကို သတ်ပြီး ပြန်စပေးခြင်း။
- **Environment Security:** Telegram Bot Token နှင့် Sensitive Data များကို GitHub Secrets တွင် လုံခြုံစွာ သိမ်းဆည်းထားခြင်း။

---

## 📁 နည်းပညာနှင့် Requirements

- **Language:** Python 3.10
- **Automation:** GitHub Actions
- **Dependencies:** `requirements.txt`
